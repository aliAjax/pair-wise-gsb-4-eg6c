# 声线练习室 Pronunciation Lab

纯前端发音练习应用（React + Vite + TypeScript），数据保存在 localStorage。

## 复练闭环规则

- **版本历史**：每句保留全部版本与练习记录（录音得分、时长、日期）。修改句子会生成新版本，旧版本的录音、得分与掌握状态仍归旧版本。
- **掌握判定**：绑定在当前版本上 —— 同一版本需跨 2 天完成练习，且最新评分 ≥ 85 分，才标记为已掌握；达标后再修改句子会生成新版本并回到练习中。
- **归档 / 恢复**：有练习历史的句子归档时必须填写原因，归档后退出今日待练；恢复时生成新版本继续练习，不覆盖归档前的任何记录。
- **一致性**：版本、掌握状态与今日待练队列全部由持久化的版本记录推导，刷新后保持一致。
